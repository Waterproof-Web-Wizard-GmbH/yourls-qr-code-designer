# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Use [GitHub private vulnerability reporting](https://github.com/Waterproof-Web-Wizard-GmbH/yourls-qr-code-designer/security/advisories/new) or write to hallo@waterproof.agency with the subject "Security: yourls-qr-code-designer".

We confirm receipt within three working days and aim to ship a fix within 14 days for confirmed issues.

## Scope

The plugin renders QR codes in the browser and stores nothing on the server. Relevant reports concern output escaping, input handling on the designer page, and the bundled qr-code-styling library.
